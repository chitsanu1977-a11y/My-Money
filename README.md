# เงิน.ฉัน 💚

แอปบันทึกรายรับรายจ่ายส่วนตัว ติดตั้งเป็นแอปมือถือได้ผ่าน GitHub Pages

## ฟีเจอร์

- 📊 **Dashboard** สรุปยอดรวม รายรับ-รายจ่ายเดือนนี้
- 💼 **กระเป๋าหลายใบ** เงินสด / ธนาคาร / ออมสิน / E-Wallet / บัตรเครดิต
- 🔄 **โอนเงินระหว่างกระเป๋า** ได้ทันที
- 🏷️ **หมวดหมู่** รายรับ 8 หมวด / รายจ่าย 12 หมวด
- 🤝 **หนี้สิน** ทั้งเราเป็นหนี้ และคนอื่นยืมเรา + ติดตามการชำระ
- 📈 **วิเคราะห์** กราฟ 6 เดือน, breakdown หมวดหมู่, อัตราออมเงิน
- 📱 **PWA** ติดตั้งเป็นแอปในมือถือได้
- 💾 **localStorage** ไม่ต้องมี backend, ข้อมูลอยู่ในเครื่อง

## ติดตั้งบน GitHub Pages

1. สร้าง repo ใหม่ (เช่น `money-app`)
2. อัพโหลดไฟล์ทั้งหมด: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`
3. ไปที่ Settings → Pages → Branch: main → Save
4. เปิดลิงก์ `https://[username].github.io/money-app/`
5. กด "เพิ่มลงหน้าจอหลัก" ในมือถือ

## ติดตั้งเป็นแอปมือถือ

**iPhone/iPad (Safari):**
1. เปิดลิงก์ใน Safari
2. กดปุ่ม Share (กล่องมีลูกศรชี้ขึ้น)
3. เลือก "เพิ่มลงในหน้าจอโฮม"

**Android (Chrome):**
1. เปิดลิงก์ใน Chrome
2. กดจุด 3 จุด ด้านบนขวา
3. เลือก "เพิ่มลงในหน้าจอหลัก"

## หมายเหตุ

- ข้อมูลเก็บใน localStorage ของเครื่อง
- หากต้องการสำรองข้อมูล แนะนำถ่ายภาพหน้าจอหรือ export (feature อนาคต)
- ไม่มีการส่งข้อมูลออกไปที่ใด ปลอดภัย 100%
